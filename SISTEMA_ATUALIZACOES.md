# Sistema - Atualizacao Atual

Atualizado em: 28/04/2026.

## Cobranca Offline
- A cobranca de usuarios offline agora e enviada somente por DM.
- O envio automatico acontece as 19:00 no horario de Sao Paulo.
- O mesmo usuario so recebe nova cobranca depois de 2 dias.
- Usuarios com ausencia ativa nao recebem essa cobranca.
- O `/painel > Cobrancas` mostra a regra atualizada.
