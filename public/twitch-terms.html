Termos de Uso — Bot Vortex

Ao utilizar o Bot Vortex, voce concorda com os termos descritos abaixo.

  • 1. Uso do Servico
    O Bot Vortex e um sistema automatizado integrado ao Discord que permite a exibicao e envio de notificacoes de transmissoes ao vivo da plataforma Twitch.
  • 2. Coleta de Dados
    O sistema podera coletar e armazenar: ID do usuario no Discord, nome de usuario, ID do servidor e canal da Twitch vinculado.
  • 3. Finalidade dos Dados
    Os dados sao utilizados exclusivamente para identificar o usuario dentro do sistema, enviar alertas automaticos de live e exibir informacoes no painel administrativo.
  • 4. Compartilhamento
    O Bot Vortex nao compartilha dados com terceiros.
  • 5. Responsabilidade do Usuario
    O usuario e responsavel pelas informacoes fornecidas e pelo uso do bot dentro do servidor.
  • 6. Modificacoes
    Os termos podem ser alterados a qualquer momento sem aviso previo.
  • 7. Aceitacao
    Ao utilizar o bot, o usuario declara estar ciente e de acordo com estes termos.

Politica de Privacidade — Bot Vortex

  • 1. Informacoes Coletadas
    Coletamos apenas dados necessarios para funcionamento do sistema: ID do Discord, nome de usuario e canal da Twitch vinculado.
  • 2. Uso das Informacoes
    Os dados sao utilizados para monitorar transmissoes ao vivo, enviar notificacoes no Discord e gerenciar funcionalidades do bot.
  • 3. Armazenamento
    Os dados sao armazenados de forma segura e nao sao vendidos ou compartilhados.
  • 4. Seguranca
    Utilizamos praticas de seguranca para proteger os dados armazenados.
  • 5. Direitos do Usuario
    O usuario pode solicitar remocao dos dados a qualquer momento.
  • 6. Contato
    Para solicitacoes, entre em contato com o administrador do bot.
Aceitar termos e continuar
