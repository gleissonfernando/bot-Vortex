Termos de Uso — Bot Vortex

1. Uso do ServicoO Bot Vortex e um sistema automatizado integrado ao Discord para gerenciamento administrativo de servidores.
2. Coleta de DadosO sistema podera coletar ID do usuario no Discord, nome de usuario, ID do servidor e registros operacionais gerados pelo uso do bot.
3. Finalidade dos DadosOs dados sao usados para identificar usuarios, gerar relatórios, controlar permissões e exibir informacoes no painel administrativo.
4. CompartilhamentoO Bot Vortex nao compartilha dados com terceiros.
5. Responsabilidade do UsuarioO usuario e responsavel pelas informacoes fornecidas e pelo uso do bot dentro do servidor.
6. ModificacoesOs termos podem ser alterados a qualquer momento sem aviso previo.
7. AceitacaoAo utilizar o bot, o usuario declara estar ciente e de acordo com estes termos.

Politica de Privacidade — Bot Vortex

1. Informacoes Coletadas: coletamos apenas dados necessarios para funcionamento do sistema: ID do Discord, nome de usuario, cargos, registros de ponto e dados administrativos configurados no servidor.

2. Uso das Informacoes: os dados sao utilizados para relatórios, controle de permissões, painéis administrativos e funcionalidades internas do bot.

3. Armazenamento: os dados sao armazenados de forma segura e nao sao vendidos ou compartilhados.

4. Seguranca: utilizamos praticas de seguranca para proteger os dados armazenados.

5. Direitos do Usuario: o usuario pode solicitar remocao dos dados a qualquer momento.

6. Contato: para solicitacoes, entre em contato com o administrador do bot.
